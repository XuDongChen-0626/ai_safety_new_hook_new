# Modbus RTU 寄存器映射（上位机接口）

本机在 RS485 总线（uart8，9600 8N1）上作为 **Modbus RTU 从机**，从机地址由
`CONFIG_HOOK_MODBUS_SLAVE_ID` 配置（默认 1）。寄存器地址、含义与旧固件
`application/system_def.h` 完全一致。

* 保持寄存器：地址 0..255，功能码 FC03（读）、FC06（写单个）、FC16（写多个）
* 输入寄存器：地址 0..255，功能码 FC04（读），当前保留（恒为 0）

## 上位机 → 本机（命令 / 配置）

| 地址 | 名称 | 说明 |
| --- | --- | --- |
| 0 | `CMD_LED_SWITCH` | LED 慢闪开关：1 = 打开慢闪，0 = 关闭 |
| 1 | `CMD_BUZZER_7M` | 7 m 报警声触发：1 = 触发（3 m 优先） |
| 2 | `CMD_BUZZER_3M` | 3 m 报警声触发：1 = 触发 |
| 103 | `CMD_VOLUME` | 声光模块音量（0..31），变化后自动下发 |
| 111 | `STATUS_POWER_OFF_TIME` | 定时关机时间，北京时间为准：高字节时，低字节分（默认 0x1500 = 21:00） |
| 112 | `STATUS_POWER_ON_TIME` | 定时开机时间：高字节时，低字节分（默认 0x0600 = 06:00） |
| 115 | `STM32_STANDBY_ENABLE` | 硬待机使能：1 = 到关机时刻进入 STM32 STANDBY 并由 RTC Alarm B 唤醒 |
| 116 | `SOFT_STANDBY_ENABLE` | 软待机使能：1 = 处于关机时段时切断爆闪灯继电器（默认 1） |
| 117 | `HEARTBEAT_ENABLE` | 心跳监督使能：1 = 启用（默认），0 = 继电器常开 |

## 本机 → 上位机（状态 / 遥测）

| 地址 | 名称 | 说明 |
| --- | --- | --- |
| 100 | `STATUS_LED_SWITCH` | 灯光功能状态：1 = 正在按“亮 2 s / 灭 1 s”闪烁（或报警声期间），0 = 已彻底关闭 |
| 101 | `STATUS_BUZZER` | 喇叭状态：0 = 关闭，1 = 7 m 报警，2 = 3 m 报警 |
| 102 | `STATUS_BMS_BATTERY` | BMS 电量；读取失败时为 0 |
| 104 | `STATUS_HEART_BEAT` | **上位机心跳计数器**，上位机周期性写入（值变化即视为心跳） |
| 105 | `STATUS_BMS_REMAIN_DISCHARGE_TIME` | 剩余放电时间（分钟，20 次采样平均；无效为 0xFFFF） |
| 106 | `STATUS_WORK_MODE` | 工作模式：0 待机、1 正常、2 低电量、3 故障 |
| 107 | `STATUS_BMS_IS_charge` | 0 放电、1 充电、2 静止 |
| 108 | `STATUS_BMS_REMAIN_CHARGE_TIME` | 剩余充电时间（分钟，20 次采样平均；无效为 0xFFFF） |
| 109 | `STATUS_BMS_TOTAL_VOLTAGE` | BMS 总电压 |
| 110 | `STATUS_BMS_TOTAL_CURRENT` | BMS 总电流（取绝对值） |
| 113 | `REG_ERROR_CODE` | 系统错误码，见下表 |
| 114 | `RTC_TIME` | 当前北京时间：高字节时，低字节分 |
| 118 | `STATUS_BMS_PROTECT_STATUS` | BMS 保护状态寄存器（原样透传） |

## 错误码（寄存器 113）

| 位 | 名称 | 含义 | 心跳灯表现 |
| --- | --- | --- | --- |
| 0x01 | `ERR_HEARTBEAT_TIMEOUT` | 上位机心跳丢失 > 60 s（继电器已断开，寄存器 3） | 每秒闪 1 次，间隔 2 s |
| 0x02 | `ERR_LED_OFFLINE` | 声光报警模块连续 3 次写超时（写超时约 1 s/次，≈4 s 内可判定） | 每秒闪 2 次，间隔 2 s |
| 0x04 | `ERR_BMS_READ_FAIL` | BMS 读取失败（25 s 内无成功读取） | 每秒闪 3 次，间隔 2 s |
| 多位同时置位 | — | 多重故障 | 快闪（爆闪） |

错误码为 0 时心跳灯为 1 s 亮 / 1 s 灭。

## 声光模块 LED 控制（最新固件行为）

模块内部的“慢闪”指令已不再使用，改由本机生成闪烁节拍：

| 步骤 | 时长 | 下发指令（写寄存器 0x00C2） |
| --- | --- | --- |
| 点亮 | 8 × 250 ms = 2 s | `0x0041` (`CMD_LED_ON`) |
| 熄灭 | 4 × 250 ms = 1 s | `0x0060` (`CMD_LED_OFF`) |

* 触发条件：`CMD_LED_SWITCH`(0) = 1 **或** `STATUS_BUZZER`(101) ≠ 0（报警声期间同步闪烁）。
* 板载 `PWD_LED`(PB3) 直接镜像 `CMD_LED_SWITCH`（上电默认低），不再表示继电器状态。
* 继电器状态由 `FLASH_LIGHT_POWER_EN`(PE5) 单独控制，心跳超时断开继电器不影响 PWD_LED。
* 每次步进变化或检测到 `ERR_LED_OFFLINE` 时才下发一次指令（避免总线刷屏）。

## 内部 Modbus 主机（本机作为主机）

| 总线 | 外设 | 从机地址 | 说明 |
| --- | --- | --- | --- |
| RS485 | usart6 | 2 | BMS：电量、总电压/电流、保护状态、剩余充放电时间 |
| RS485 | uart7 | 1 | 声光报警模块：LED 控制 0x00C2、声光触发 0x0003、音量 0x0006、停止 0x000E |

## 云端二进制协议（4G 通道）

4G 模块（usr.cn 透传）在串口上以 `"<通道>,"` 前缀区分数据：

| 前缀 | 方向 | 含义 |
| --- | --- | --- |
| `1,` | 云端 → 本机 | 文本命令：`craner#AT...`（本机处理）或 `usr.cn#AT...`（转发给 4G 模块） |
| `2,` | 云端 → 本机 | 保留，忽略 |
| `3,` `4,` | 云端 → 本机 | 二进制 0xA5 帧 |
| `3,` | 本机 → 云端 | 二进制 0xA5 应答帧 |

帧格式：`0xA5 | SEQ | ID | LEN | DATA... | CRC16(低字节在前)`，
CRC 为 CRC16-CCITT（多项式 0x1021，初值 0x0000）。

命令 ID：0x01 灯光/声光控制、0x02 BMS 查询、0x04 心跳使能、0x05 工作心跳、
0x06 工作模式（只读）、0x07 软待机使能、0x08 定时开关机、0x09 当前时间、
0xF0 系统错误码。应答 ID 为命令 ID 加 0x80（`0x81`..`0x85`），错误应答在
数据段返回错误码（0x01 CRC、0x02 长度、0x03 未知 ID、0x04 不可读写）。

各命令数据段（与最新固件一致）：

| ID | 读应答 | 写请求 |
| --- | --- | --- |
| 0x01 灯光 | 1 字节：bit0 灯光功能、bit1 7 m 声、bit2 3 m 声、bit3..7 音量 | 1 字节同上（写）|
| 0x02 BMS | 12 字节小端：电量、总压、总流、剩余放电、剩余充电、保护状态 | 写请求返回 0x04 |
| 0x04 心跳使能 | 1 字节 | 1 字节 |
| 0x05 工作心跳 | 1 字节 | 写入不回应答 |
| 0x06 工作模式 | **2 字节**：`[mode, error_code]`，仅当 mode=3(DEVICE_ERROR) 时第 2 字节为错误码，否则为 0 | 只读，写请求返回 0x04 |
| 0x07 软待机使能 | 1 字节 | 1 字节 |
| 0x08 定时开关机 | 4 字节小端：开机、关机 | 4 字节同上 |
| 0x09 当前时间 | 2 字节小端 `hh:mm` | 2 字节同上 |
| 0xF0 系统错误码 | 1 字节错误码 | — |
